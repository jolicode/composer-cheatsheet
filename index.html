Composer Cheat Sheet for developers

Composer is the dependency manager for PHP and you are on a one-page-only documentation for this tool. Official documentation is on the official website, this page just brings you the essential.

This is an interactive guide for exploring various important properties of the composer.json file: hover over any property of the example below to see its documentation.

One line installer

curl -sS https://getcomposer.org/installer | php

composer.phar most needed command line

$ composer require <package>$ composer install$ composer update <package>$ composer update --lock$ composer dump-autoload --optimize
